## 体验版（空数据 + 引导 + 可编辑资料）

- 文件：`basely-demo.html`（打开即弹 8 步应用指引；账本为空，可自己记第一笔）
- 生成：`node tools/make-demo.mjs`（同样从 app.html 生成）
- 资料：我的页点头像即可改昵称 / 签名 / 头像，存在 `basely.demo.profile`
- 数据：体验版用独立存储键 `basely.demo.v1`，不会污染正式原型；清空浏览器数据即恢复初始状态
- 重看指引：控制台执行 `__BASELY_DEMO_TOUR__()`

## 手机版（扫码演示）

- 文件：`basely-mobile.html`（只保留 App 本体，去掉外框 / 侧栏 / 假状态栏，按屏幕等比缩放）
- 生成：`node tools/make-mobile.mjs`（从 app.html 生成，改完 app.html 重跑一次即可）
- 打开：双击 `启动.bat`，控制台会打印局域网地址，手机扫码用 `http://<电脑IP>:5173/basely-mobile.html`；手机与电脑需同一 Wi-Fi

> 开发汇报：`Basely-代码开发汇报.pdf`（11 页 A4 横版，讲架构 / 数据 / 交互 / AI 接入 / 踩坑与验证；源文件 `report.html`，改动后用 Edge「打印为 PDF」重新导出即可）

## 快速打开

| 方式 | 步骤 | AI 助手 |
| --- | --- | --- |
| **A. 直接双击** | 打开 `index.html` 或 `app.html` | 走本地回复（浏览器直连大模型会被 CORS 拦住） |
| **B. 本地服务（推荐）** | 双击 `启动.bat`，或命令行 `node server.mjs`，然后访问 `http://localhost:5173/app.html` | 配好 Key 后即为真实大模型对话 |

> 只有 Node.js 一个前提（18+），`server.mjs` 零依赖。

### 接入免费大模型

1. 到 [智谱开放平台](https://open.bigmodel.cn) 注册，创建 API Key（`glm-4-flash` 目前免费）。
2. 把 `llm.config.example.json` 复制成 `llm.config.json`，填入 `apiKey`。
3. 重新双击 `启动.bat`。

也可以换成任意 OpenAI 兼容服务（改 `baseURL` / `model` 即可）：

| 服务 | baseURL | model |
| --- | --- | --- |
| 智谱 GLM-4-Flash（免费） | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| 硅基流动 SiliconFlow | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-7B-Instruct` |
| 本地 Ollama（完全离线） | `http://127.0.0.1:11434/v1` | `qwen2.5` |

> 也可以用环境变量：`set LLM_API_KEY=xxx` 后再运行 `server.mjs`；不写 Key 也能跑，平平会用本地回复，并在对话头部标注「本地回复」。

## 页面与功能

### 品牌站 `index.html`
- **首屏**：主张「没乱花，它占了 25.3%」，右侧是真实运行截图，浮动卡片显示刚需 / 溢价率。
- **基线带**：上半浅黄（伪刚需）、下半浅蓝（刚需），中间一条深蓝分界线 —— 与 App 图标、图表同一套语义。
- **问题 / 机制 / 界定**：三个解释不通的日常、爱好如何隐形、刚需与伪刚需的定义。
- **算法**：`溢价金额 = Σ(单笔 − 基线)`、`溢价率 = 溢价 ÷ 总支出`，附 ¥506 → 25.3% 的拆解。
- **小额高频**：62 笔 ≤30 元 = ¥1,116（55.8%）。
- **方案**：S1–S5 五步，机器三步、人两步；三条设计原则。
- **功能**：总览 / 明细 / 备注 / AI 助手 / 心愿存钱罐。
- **界面**：四张 2× 界面截图。
- **IP**：3D 毛绒版与平面矢量版可切换，含三视图、表情库、待机与交互动作关键帧。
- **小组件**：小尺寸、中尺寸、隐私模式。
- **海报**：六张，点击放大，支持键盘左右键与 Esc。
- **品牌**：图文标志、App 图标、四个品牌色。

### App 原型 `app.html`
底部五个 Tab：首页 / 账单 / ＋ / 图表 / 我的，另有添加记账、分类、AI 助手、预算计划、预算设置、成就、设置、心愿存钱罐。

- **只记支出**：没有收入页、没有收支对比。Basely 关心的是「这笔钱姓什么」，不是结余。
- **首页即入口**：本月总览 → 心愿存钱罐 → 分类预算 → 平平 → 今日账单，每块卡片都能点进去看详情。
- **记一笔**：数字键盘 → 选分类 → 自动比对「你的基线」→ 人确认「这笔姓生活还是姓爱好」。点金额或「收起」可以暂时放下键盘，去改日期 / 账户 / 备注，再点「保存这笔」。
- **改判**：点任意一笔，在抽屉里改判刚需 / 伪刚需，溢价率立刻重算；账单页还能按「全部 / 刚需 / 伪刚需」筛选。
- **图表**：周分析（堆叠柱）与月分析（面积折线）切换，环形图随所选区间变化，平平的点评随数据变化。
- **预算**：四个滑杆调整刚需 / 伪刚需分配，金额实时换算。
- **存钱罐**：首页可直接看到进度，点进详情存入 ¥100 / ¥500 / ¥1,000，水位与百分比随之上涨。
- **AI 助手**：平平会按你的实际数据回答（餐饮溢价、本周趋势、预算建议、心愿进度）。
- **平平气泡**：每一页右下角都蹲着一只平平，作为去 AI 助手的快捷入口；姿势取自 IP 的「待机动作（记录 / 喝咖啡 / 看账本）」与「交互动作（待机 / 过渡 / 工作）」，会随页面切换，点一下会挥手并换成对话状态。

窄屏（≤560px）自动铺满全屏，可直接在手机上使用。

## 数据口径

与设计稿严格一致，`assets/js/data.js` 由 `tools/gen-data.mjs` 生成并校验：

| 项 | 数值 |
| --- | --- |
| 本月日常支出 | ¥2,000 = 餐饮 1,000 + 日用 600 + 出行 400 |
| 溢价（伪刚需） | ¥506 = 330 + 96 + 80 |
| 溢价率 | 506 ÷ 2000 = **25.3%** |
| 刚需 | ¥1,494（74.7%） |
| 小额支出 | 62 笔 ≤30 元，合计 ¥1,116（55.8%） |

共 101 条流水，金额逐笔加总严格等于上表；生成脚本内置断言，改数字会直接报错。
新增一笔账时，新记录同样计入上述统计，不会出现「界面显示与数据不符」。

## 关于「形象零改动」

| 资产 | 处理方式 |
| --- | --- |
| App 图标 `app-icon.png` | 从 `基线Basely图标_平面配色微调版.png` 裁切圆角方形，未改配色与构图 |
| 图文标志 `logo-lockup.png` / `-white.png` | 从 `基线Basely单色图文Logo.png` 提取，仅去掉白底与背景噪点、裁掉留白；深色底用反白版 |
| 平平 IP | 从 `平平3D三视图`、`平平3D表情库`、`平平平面三视图`、`平平平面表情库`、待机 / 交互关键帧中裁切去底，作为独立素材使用 |
| 分类图标 | 从 UI 设计稿中按原尺寸裁切（餐饮 / 日用 / 出行 / 购物 / 娱乐 / 休闲 / 医疗 / 学习） |
| 海报 | 原图压缩为 JPEG，未裁切、未调色 |

没有重新绘制企鹅、没有更换图形风格、没有修改品牌色。
唯一的重绘是导航、开关、删除等**通用界面线性图标**，它们不属于品牌资产。

## 技术与适配

- 原生 HTML / CSS / JS，零框架零依赖；图表为手写 SVG，随数据重算。
- 设计令牌集中在 `assets/css/tokens.css`（品牌色、圆角、阴影、字体栈），两套页面共用。
- 桌面优先，1020px / 720px / 560px 三档断点；支持 `prefers-reduced-motion`。
- 截图校样模式：`index.html?still=1`、`app.html?still=1` 会关闭所有过渡动画，便于逐帧比对。

## 已知限制

- 数据为模拟数据（与设计稿的示意数据一致），无后端、无账号体系。
- AI 助手为本地规则匹配，不接入大模型。
- 「授权接入支付平台」「手动录入」等路径只做到界面与文案层，不涉及真实支付数据。
